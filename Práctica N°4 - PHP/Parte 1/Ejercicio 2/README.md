# Ejercicio 2

## a) ¿Son equivalentes?

**Sí.** Los tres códigos muestran la misma salida:

```text
12345678910
```

La diferencia está en que utilizan distintas formas de repetición: `while`, `while...endwhile` y `do...while`.

## b) ¿Son equivalentes?

**Sí.** Los cuatro códigos muestran la misma salida:

```text
12345678910
```

Utilizan distintas formas de escribir un bucle `for`, incluyendo el uso de `break`.

## c) ¿Son equivalentes?

**Sí.** Los dos códigos funcionan de la misma manera.

Según el valor de `$i`:

```text
0 → i equals 0
1 → i equals 1
2 → i equals 2
```

Para cualquier otro valor no se muestra ningún mensaje.
