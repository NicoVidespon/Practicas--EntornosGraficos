# Ejercicio 1

## 1. Variables y tipos

* `$a` → **boolean** (`TRUE`).
* `$b` → **string** (`"xyz"`).
* `$c` → **string** (`"xyz"`).
* `$d` → **integer** (`12`).
* `$i` → parámetro de la función `doble()`.
* `$f` y `$g` → variables utilizadas para almacenar resultados.

## 2. Operadores

* `=` → asignación.
* `*` → multiplicación.
* `+=` → suma y asignación.
* `++` → incremento.
* `? :` → operador ternario.

## 3. Funciones

* `doble($i)` → devuelve el doble del valor recibido.
* `gettype()` → indica el tipo de una variable.
* `is_int()` → verifica si una variable es entera.
* `is_string()` → verifica si una variable es de tipo string.

## 4. Estructuras de control

Se utilizan dos estructuras `if` y un operador ternario `? :`.

## 5. Valores finales

```text
$a = TRUE
$b = "xyz"
$c = "xyz"
$d = 18
$f = 44
$g = 44
```

## 6. Salida

```text
booleanstringstringinteger1xyzxyz184444
```
