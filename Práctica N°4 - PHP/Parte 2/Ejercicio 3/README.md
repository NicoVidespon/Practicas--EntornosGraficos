# Ejercicio 3

En cada caso, indicar las salidas correspondientes.

## a)

La función `getdate()` devuelve información sobre la fecha y hora actual. Por eso, la salida depende del momento en que se ejecute el programa.

**Salida:**

```text id="dzen4a"
Has entrado en esta pagina a las HH horas, con MM minutos y SS segundos, del DD/MM/YYYY
```

Los valores de hora, minutos, segundos, día, mes y año cambian según el momento de ejecución.

## b)

La función `sumar()` recibe dos números, los suma y muestra el resultado.

Al ejecutar `sumar(5,6);`:

**Salida:**

```text id="esyc5j"
5+6=11
```
