# Ejercicio 1

## ¿Son equivalentes?

**Sí, los dos códigos son equivalentes.**

En ambos casos se crea el mismo array con:

* `color` → `rojo`
* `sabor` → `dulce`
* `forma` → `redonda`
* `nombre` → `manzana`
* `0` → `4`

En el primer código se crea todo el array directamente con `array()`, mientras que en el segundo los elementos se agregan uno por uno.

Por lo tanto, **el contenido final del array es el mismo**.
