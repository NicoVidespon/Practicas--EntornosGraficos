# Ejercicio 3

## 3.A) ¿Qué formatos soporta `<video>`?

Los principales formatos utilizados con el elemento `<video>` de HTML5 son:

* **MP4** — `.mp4` — `video/mp4`
* **WebM** — `.webm` — `video/webm`
* **OGG** — `.ogv` — `video/ogg`

### Explicación

* `<video>` crea el reproductor de video.
* `controls` muestra los controles de reproducción.
* `width="640"` establece el ancho del reproductor.
* `<source>` indica la ubicación y el tipo del archivo.
* `type="video/mp4"` indica que el archivo utilizado es un video MP4.
