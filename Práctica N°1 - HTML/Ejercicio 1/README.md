# Ejercicio 1

## 1. ¿Cuáles son las ventajas de HTML5?

HTML5 incorpora nuevas características que facilitan el desarrollo de páginas web y permiten agregar contenido multimedia, mejorar la estructura y hacer los sitios más accesibles.

Algunas de sus principales ventajas son:

* Permite reproducir **audio y video** directamente desde el navegador.
* Incorpora nuevos tipos de campos para formularios, como `email`, `date`, `number` y `color`.
* Agrega **elementos semánticos** como `<header>`, `<nav>`, `<section>`, `<article>` y `<footer>`.
* Permite trabajar con gráficos mediante **Canvas y SVG**.
* Mejora la **accesibilidad** y la organización del contenido.
* Facilita la adaptación de las páginas a **dispositivos móviles**.
* Incluye herramientas para la **validación de formularios**.

## 2. ¿Por qué utilizar HTML5?

HTML5 permite desarrollar sitios web con características modernas sin depender tanto de tecnologías externas. También mejora la estructura del código, el uso de contenido multimedia, los formularios y la compatibilidad con distintos dispositivos.

## 3. Nombre ventajas

Algunas de las principales ventajas de HTML5 son:

* Audio y video nativos.
* Nuevos tipos de formularios.
* Validación de formularios.
* Elementos semánticos.
* Mayor accesibilidad.
* Compatibilidad con dispositivos móviles.
* Soporte para Canvas y SVG.
* Menor dependencia de plugins externos.
